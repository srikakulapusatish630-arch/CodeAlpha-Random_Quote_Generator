# Random Quote Generator

## About the Project
The Random Quote Generator is a simple Python project that displays random inspirational quotes along with their authors. The quotes are stored in a CSV file for easy access and management.

## Features
- Generates random inspirational quotes.
- Displays the quote and author's name.
- Stores quotes in a CSV file.
- Easy to use and beginner-friendly.

## Technologies Used
- Python
- Google Colab
- CSV (Comma-Separated Values)

## Project Files
- `Random_Quote_Generator.ipynb` — Python notebook containing the project code.
- `random_quotes.csv` — CSV file containing quotes and authors.
- `README.md` — Project documentation.

## How to Run
1. Download or clone this repository.
2. Open `Random_Quote_Generator.ipynb` in Google Colab.
3. Run the code cells.
4. Click the **New Quote** button to generate a random quote.
